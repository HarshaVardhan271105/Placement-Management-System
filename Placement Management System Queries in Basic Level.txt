Placement Management System Queries in Basic Level:

1)Retrieve all records from the department table?
Ans:select * from department;

2)Retrieve the details of companies located in 'hyderabad'?
Ans:select * from companies where location = 'hyderabad';

3)Display all placement drives in ascending order based on their drive date?
Ans:select * from placement_drives order by drive_date asc;

4)Display all unique application statuses from the applications table?
Ans:select distinct status from applications;

5)Retrieve all placement drives scheduled between '2026-11-10' and '2026-11-18'?
Ans:select * from placement_drives where drive_date between '2026-11-10' and '2026-11-18';

6)Retrieve all companies whose names start with the letter 'a'?
Ans:select * from companies where company_name like 'a%';

7)Retrieve all applications whose status is either 'selected' or 'pending'?
Ans:select * from applications where status in ('selected', 'pending');

8)Retrieve all applications whose status is neither 'selected' nor 'rejected'?
Ans:select * from applications where status not in ('selected', 'rejected');

9)Retrieve the first three companies from the companies table?
Ans:select * from companies limit 3;

10)Retrieve the placement drives where the company_id is 1 and the eligibility is 'minimum 7.0 cgpa'?
Ans:select * from placement_drives where company_id = 1 and eligibility = 'minimum 7.0 cgpa';

11)Retrieve all companies located in either 'hyderabad' or 'bangalore'?
Ans:select * from companies where location = 'hyderabad' or location = 'bangalore';

12)Find the total number of applications submitted by students?
Ans:select count(*) as total_applications from applications;

13)Calculate the total package offered in all placement results?
Ans:select sum(package) as total_package from placement_results;

14)Calculate the average package offered to selected students?
Ans:select avg(package) as average_package from placement_results where status = 'selected';

15)Find the lowest package offered to students?
Ans:select min(package) as lowest_package from placement_results;

16)Find the highest package offered to students?
Ans:select max(package) as highest_package from placement_results;

17)Retrieve all placement results where the package is not available?
Ans:select * from placement_results where package is null;

18)Display company names using the column heading 'organization'?
Ans:select company_name as organization from companies;

19)Count the number of applications for each application status?
Ans:select status, count(*) as total_applications from applications group by status;

20)Display application statuses that have more than one application?
Ans:select status, count(*) as total_applications from applications group by status having count(*) > 1;

21)Display all companies except those located in Hyderabad?
Ans:select * from companies where location <> 'hyderabad';

22)Count the number of different departments in the students table?
Ans:select count(distinct dept_id) as total_departments
from students;

23)Change the location of the company with company_id = 2 to Hyderabad?
Ans:update companies set location = 'hyderabad' where company_id = 2;

24)Display placement results where package is available?
Ans:select * from placement_results where package is not null;

25)Delete the skill mapping for student 105 and skill 4 from the student_skills table?
Ans:delete from student_skills where student_id = 105 and skill_id = 4;

26)Display placement results where the status is available and package is not null?
Ans:select * from placement_results where status is not null
and package is not null;

27)Display the number of students in each department?
Ans:select dept_id, count(*) as total_students from students
group by dept_id;
