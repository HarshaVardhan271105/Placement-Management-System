Placement Management System Queries in High Level:

1)create a view to display student names, application dates, and application statuses?
Ans:create view student_application_view as
select s.name, a.apply_date, a.status
from students s
inner join applications a
on s.student_id = a.student_id;

2)display all records from the created view?
Ans:select * from student_application_view;

3)display only selected applications from the view?
Ans:select * from student_application_view where status = 'selected';

4)create a view to display company names, locations, and placement drive dates?
Ans:create view company_drive_view as
select c.company_name, c.location, p.drive_date
from companies c
inner join placement_drives p
on c.company_id = p.company_id;

5)change the view definition to display company names and locations only?
Ans:create or replace view company_drive_view as
select company_name, location
from companies;

6)remove the company drive view?
Ans:drop view company_drive_view;

22)create a trigger to prevent inserting an invalid application status?
Ans:delimiter //
create trigger check_application_status
before insert on applications
for each row
begin
if new.status not in ('pending', 'selected', 'rejected') 
then
signal sqlstate '45000'
set message_text = 'invalid application status';
end if;
end //
delimiter ;

23)test the trigger with a valid application status?

24)prevent updating a placement package to a negative value?
Ans:delimiter //
create trigger check_package_before_update
before update on placement_results
for each row
begin
if new.package < 0 then
signal sqlstate '45000'
set message_text = 'package cannot be negative';
end if;
end //
delimiter ;
